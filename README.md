# 🧪 한일청소년과학제전 소개 반응형 웹사이트

> 청소년을 위한 과학의 제전 2026 전국대회(동경청소년과학제전 @ 과학기술관)와 오사카대회(Science Festival 2026 in Osaka @ 오사카 교육대학 텐노지 캠퍼스)를 한국어로 소개하는 종합 안내 웹사이트

## ✨ 주요 기능 & 콘텐츠

- 🏫 **공식 개최지 완벽 적용**: 도쿄 키타노마루 공원 **과학기술관(科学技術館)** & 오사카 **오사카 교육대학 텐노지 캠퍼스(미래교육 공창센터 & 서관)**
- 💬 **동경 사이언스 커뮤니케이션**: "왜 그럴까/어떻게 응용할까" 대화 중심 56개 부스 및 10:30, 12:30, 14:30 참가권 타임슬롯 안내
- 🎭 **오사카 3대 프로그램 유형**: A) 부스 시연&공작 (500~2000세트 키트), B) 실내 대형 무대 쇼 (25~60분), C) 야외 대형 무대 쇼 (캠퍼스 운동장)
- 🎨 **한국형 태극 브랜드 로고**: 흑백 단색 텍스트 & 태극 원자 궤도 SVG 모던 로고
- 🌙 **다크/라이트 테마** – CSS Custom Properties + LocalStorage 영속
- 📱 **반응형 디자인** – 모바일(375px) ~ 데스크탑(1440px) 완벽 대응
